# Skille Claude dla tego repozytorium

Claude Code wczytuje ten katalog automatycznie na starcie każdej sesji z tym repozytorium
(w chmurze i lokalnie). Każdy podkatalog to jeden skill (`SKILL.md` + materiały).

| Skill | Do czego | Źródło |
|---|---|---|
| `android-build` | Android SDK w sesji, budowanie, podpis, CI, wydania, przekazanie i weryfikacja APK | własny |
| `systematic-debugging` | Szukanie przyczyny błędu zamiast zgadywania | obra/superpowers (MIT) |
| `test-driven-development` | Najpierw test, potem kod | obra/superpowers (MIT) |
| `verification-before-completion` | Sprawdź, zanim ogłosisz, że działa | obra/superpowers (MIT) |
| `receiving-code-review` | Rzeczowa reakcja na uwagi z przeglądu kodu | obra/superpowers (MIT) |

Szczegóły źródeł i licencji: `THIRD_PARTY.md`. Skille działają z uprawnieniami Claude,
więc nowe dodawaj dopiero po przeczytaniu ich treści i skryptów.
